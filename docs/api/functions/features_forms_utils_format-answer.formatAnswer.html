    Function formatAnswer

    • formatAnswer(valor: string | null | undefined): string

      Formats a stored form answer (respostas_formulario.valor_preenchido) into a human-readable string for display and export.

      Parameters

      • valor: string | null | undefined

        The raw stored value, or null/undefined when unanswered.

      Returns string

      The display string (e.g. "Sim", "Não", "Opção 1, Opção 2").

      Remarks

      Yes/no answers are stored lowercase ("sim"/"nao") and choice lists as a JSON { selected, other } object (legacy answers may be a plain JSON array). Both shapes are normalized here: yes/no becomes "Sim"/"Não" and a choice list becomes its selected options joined by ", " (a selected "Outro" is replaced by its typed text). Empty answers return an en dash.
